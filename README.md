# Wanted: Echoline

A story-driven pixel-art action platformer by Rifted Games.

**Play:** https://riftedgames101.github.io/wanted-echoline/

**Install on your phone**
- iPhone: open the link in Safari, tap Share, then **Add to Home Screen**.
- Android: open the link in Chrome, tap the menu, then **Install app**.

Also on itch.io: https://rifted-games-101.itch.io/wanted-echoline
